# Find the Frog

A small logic puzzle. One frog hides in every colored pond.

- One frog per color
- One frog per row and column
- Frogs cannot touch, even diagonally

Tap a cell to mark an X, tap again to place a frog, tap again to clear. A frog on a wrong cell costs a heart (3 hearts). Placing a frog crosses out its row, column, neighbours and pond.

Boards: 6x6, 8x8, 10x10. Puzzles are generated in the browser and each has exactly one solution. Single static file (`index.html`), no dependencies. Original art and code.
