# Find the Frog

A small logic puzzle. One frog hides in every colored pond.

- One frog per color
- One frog per row and column
- Frogs cannot touch each other - no other frog in any of the 8 cells around one

Tap a cell to pencil a light X note, tap again to place the frog, tap again to clear. A frog on a wrong cell costs a heart (3 hearts). Placing a frog automatically crosses out its row, column, the 8 cells around it and its pond with dark X marks.

Boards: 6x6, 8x8, 10x10. Puzzles are generated in the browser and each has exactly one solution. Single static file (`index.html`), no dependencies. Original art and code.
